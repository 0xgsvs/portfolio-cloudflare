// PRIORITY ISSUES
HIGH / ACCESSIBILITY

Placeholder is doing the label's job on both terminal inputs

src/pages/404.astro:49 and src/components/generic/TerminalOverlay.astro:18 both ship <input placeholder="Type a command..."> with no label. A screen reader announces an unnamed text field, and the only name disappears on focus.

FIX: add a real <label for> (visually hidden is fine) and keep the placeholder as an example only.
HIGH / ACCESSIBILITY

The terminal close control is a decorative dot

TerminalOverlay.astro:6 uses <span class="dot red" id="term-close-btn" style="cursor:pointer;">. It is not focusable and does not announce what it does. The mouse has a close target the keyboard does not.

FIX: make it a <button type="button" aria-label="Close terminal"> and move it out of the ornamental dot row.
HIGH / ACCESSIBILITY

Focus outline stripped with no replacement

src/styles/global.css:580–589: .terminal-input-form input { border: none; outline: none; ... }. Tab lands in the field with nothing visible to show it landed. No :focus-visible rule exists anywhere in the project.

FIX: restore :focus-visible { outline: 3px solid var(--black); outline-offset: 2px; } or an inset ring on the yellow bar.
HIGH / MOTION

Self-starting full-screen motion, no reduced-motion path

CompileScreen.astro auto-runs a full-viewport fake cargo build once per session and locks body scroll. index.astro:176 types at 40ms/char on every load. Layout.astro:45–64 repaints shadows at 60s idle and appends a toast at 120s. Commit blocks scale to 1.3 on entry. grep -rn "prefers-reduced-motion" src/ returns nothing.

FIX: wrap all of it in @media (prefers-reduced-motion: no-preference); give the overlay a skip control and never lock scroll for reduced-motion users.
HIGH / ACCESSIBILITY

10–12px text below 4.5:1 on white

Small type carries the worst ratios: global.css:465 footer and :456 contact detail at opacity 0.6, placeholder at 0.4 (:590), portrait hint at 0.4 (index.astro:67), commit-graph headers at 0.35 and stats at 0.3.

FIX: replace opacity with a solid neutral token at 4.5:1 or better (#52525b, #3f3f46) and keep decorative opacity off text entirely.
HIGH / ACCESSIBILITY

An overlay that behaves like a modal without a modal's contract

TerminalOverlay.astro:2–18 is a plain div with a clickable backdrop. Focus moves into the input but is neither trapped nor restored, and the page behind stays reachable by Tab. The overlay is also opened by a backtick key with no visible affordance.

FIX: role="dialog" aria-modal="true", inert the page behind, restore focus to the trigger on close, and expose a visible button to open it.

global.css:147 hero, :311 tech grid, :335 curl box, index.astro:65 portrait. Nothing directs the gaze; the lead element is whichever block happens to be tallest.

FIX: pick an asymmetric spine — left-aligned identity column with a right rail for the terminal and commit graph.

Feature tile grid, four times over

index.astro:42–61, 73–99, 108–114, 152–172. Projects, dev toolkit, tech stack, and contact are all uniform grids where every tile has the same weight. A portfolio has one strongest project.

MEDIUM / TYPE

Icon topper in three formats

A pixel SVG above every card heading (index.astro:79, 163), an emoji before every subpage h3 (contact.astro, gpg.astro, guestbook.astro, now.astro), and a 32×4px black bar before every section heading (global.css:228). Decoration filling a template slot.

FIX: remove the ornamental icons, or give one mark a single consistent functional slot, and delete the heading bar.
MEDIUM / TYPE

Template type with no scale

Layout.astro:19 loads Poppins 400–800; global.css:44–60 hardcodes 32/20/16px over a 15px body — steps of 12/4/1 — with per-component inline sizes from 10 to 24px.

FIX: build one token scale with a real ratio (1.25–1.33 minimum) and commit to a display face with a reason.
MEDIUM / COLOR

One palette, three sources of truth

Declared in global.css:4–14, re-declared in secret.astro:10, hardcoded in the inline scrollbar block at Layout.astro:24–29, and assigned arbitrarily per project via the color field in projects.ts. The hue carries no information.

FIX: one token source; assign surface color by meaning or stop coloring cards by index.
MEDIUM / WRITING

Blog code fences silently never render

writing.astro:176–179: if (line.startsWith('```')) { const lang = line.slice(3).trim(); return lang ? null : null; } always returns null. The Solana post's entire "Step 1: Hello World" bash block is invisible to readers.

FIX: render fenced blocks as <pre><code> and carry the language through to a class.

FIX: move to a script and announce the state change with aria-live="polite".
